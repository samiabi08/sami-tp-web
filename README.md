L'Énigme du Laboratoire Souterrain

Un jeu d'aventure textuel interactif développé en HTML et CSS où chaque décision mène vers une nouvelle page, créant une histoire ramifiée à fins multiples.

Synopsis

Vous vous réveillez dans un complexe scientifique abandonné alors qu'une alarme d'évacuation retentit. Vous devez explorer les lieux, faire les bons choix et trouver une issue avant l'activation du protocole de sécurité final.

Structure du projet

- index.html : Page d'accueil et point de départ de l'aventure.
- scene01.html à scene10.html : Les différentes scènes et embranchements de l'histoire.
- style.css : Feuille de style pour la mise en page, les arrière-plans et les boutons de choix.
- Dossier images : Illustrations dédiées à chaque scène du jeu.

Comment jouer

1. Téléchargez ou clonez le dossier du projet sur votre ordinateur.
2. Ouvrez le fichier index.html dans n'importe quel navigateur web (Chrome, Firefox, Edge, etc.).
3. Lisez la situation et cliquez sur l'un des choix proposés pour avancer dans l'histoire.

Technologies utilisées

- HTML5
- CSS
